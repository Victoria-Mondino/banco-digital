# Volta — Banco digital

Landing page de un banco digital con estética oscura premium y acento amarillo neón.
Un solo archivo (`index.html`) con HTML, CSS y JS. Usa GSAP + ScrollTrigger desde CDN.

## Ver en local

Abrí `index.html` en el navegador, o serví la carpeta:

```bash
python3 -m http.server 5174
```

## Personalizar

Cambiá el nombre del banco en la constante `BANK_NAME` al inicio del `<script>`.
Las cifras, textos legales y logos de medios son de ejemplo.
